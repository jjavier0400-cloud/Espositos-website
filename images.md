# Image manifest

Every image on the site. To swap one: put the new file in `src/assets/photos/`,
then change the file name in `src/data/site.ts`. Astro resizes it and converts it to WebP automatically.

- **AI**: generated with Higgsfield (model `gpt_image_2_6`). Mood only, never a product.

- **Site**: downloaded from espositosice.net, but it may be stock or a supplier photo. **Confirm rights with the owner.**
- **Placeholder**: no photo yet (branded "photo coming soon" box).
